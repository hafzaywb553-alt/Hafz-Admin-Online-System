اصلي بدلونونه:
- د فیلډونو ټول تنظیمات په Firestore کې آنلاین ذخیره کېږي.
- د فیلډونو بدلونونه اتومات خوندي کېږي، د خوندي کولو تڼۍ هم پاتې ده.
- د فیلډ مقام په شمېره، پورته/ښکته، او د نوي فیلډ د هدف ځای له لارې ټاکل کېږي.
- د اډمین او ریکارډونو Live همغږي د Firestore onSnapshot له لارې فعاله ده.
- Locked ریکارډ په register پاڼه کې د سمون لپاره نه پرېښودل کېږي.
- پټ ریکارډ د غیر ستر اډمین لپاره په UI کې نه خلاصیږي.
- Static او Custom fields دواړه د آنلاین fieldConfig له مخې پلي کېږي.
